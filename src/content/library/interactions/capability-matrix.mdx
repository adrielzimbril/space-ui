## API Reference

### CapabilityMatrix Props

| Prop                  | Type               | Default                | Description                                                                       |
| :-------------------- | :----------------- | :--------------------- | :-------------------------------------------------------------------------------- |
| `initialCapabilities` | `CapabilityItem[]` | `DEFAULT_CAPABILITIES` | Registered agent tool definitions, security compliance levels, and health status. |
| `autoPlay`            | `boolean`          | `true`                 | Automatically runs periodic sandbox health checks and verification runs.          |
| `speed`               | `number`           | `1`                    | Speed multiplier for verification transitions.                                    |
| `className`           | `string`           | `''`                   | Additional Tailwind utility classes for the outer container.                      |
| `onSequenceComplete`  | `() => void`       | `-`                    | Callback triggered upon completing a full capability audit pass.                  |
