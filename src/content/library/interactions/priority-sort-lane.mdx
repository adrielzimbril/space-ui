## API Reference

### PrioritySortLane Props

| Prop                 | Type         | Default         | Description                                                       |
| :------------------- | :----------- | :-------------- | :---------------------------------------------------------------- |
| `initialTasks`       | `LaneTask[]` | `DEFAULT_TASKS` | Priority-tagged agent subgoals distributed across urgency levels. |
| `autoPlay`           | `boolean`    | `true`          | Dynamically rebalances and promotes high-urgency tasks.           |
| `speed`              | `number`     | `1`             | Speed multiplier for automatic priority shift intervals.          |
| `className`          | `string`     | `''`            | Additional Tailwind utility classes for the outer container.      |
| `onSequenceComplete` | `() => void` | `-`             | Callback fired when all pending tasks in the lane are sorted.     |
