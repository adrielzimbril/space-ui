## API Reference

### CognitivePulseMonitor Props

| Prop                 | Type             | Default          | Description                                                                                  |
| :------------------- | :--------------- | :--------------- | :------------------------------------------------------------------------------------------- |
| `agents`             | `AgentProfile[]` | `AGENT_PROFILES` | Worker agent profiles with live cognitive load, token throughput, and context depth metrics. |
| `autoPlay`           | `boolean`        | `true`           | Simulates active reasoning spikes and context expansion dynamics.                            |
| `speed`              | `number`         | `1`              | Sampling frequency multiplier for neural pulse waves.                                        |
| `className`          | `string`         | `''`             | Additional Tailwind utility classes for the outer container.                                 |
| `onSequenceComplete` | `() => void`     | `-`              | Callback fired upon completing a full cognitive monitoring epoch.                            |
