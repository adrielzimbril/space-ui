## API Reference

### AgentActivityFeed Props

| Prop           | Type                     | Default     | Description                                                  |
| :------------- | :----------------------- | :---------- | :----------------------------------------------------------- |
| `preset`       | `AgentActivityPresetKey` | `'general'` | Active preset stream containing agent operational telemetry. |
| `autoPlay`     | `boolean`                | `true`      | Cycles through event filters and presets automatically.      |
| `speed`        | `number`                 | `1`         | Speed multiplier for auto-advance transitions.               |
| `pauseOnHover` | `boolean`                | `true`      | Pauses autonomous cycling while pointer is over the frame.   |
| `className`    | `string`                 | `''`        | Additional Tailwind utility classes for the outer container. |
