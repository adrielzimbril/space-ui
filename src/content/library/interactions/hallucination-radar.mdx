## API Reference

### FactGroundingRadar Props

| Prop                 | Type          | Default       | Description                                                                            |
| :------------------- | :------------ | :------------ | :------------------------------------------------------------------------------------- |
| `claims`             | `FactClaim[]` | `FACT_CLAIMS` | Claims under evaluation with provenance source links and grounding confidence indices. |
| `autoPlay`           | `boolean`     | `true`        | Performs continuous rotational radar sweeps and claim evaluations.                     |
| `speed`              | `number`      | `1`           | Radar angular velocity and evaluation speed multiplier.                                |
| `className`          | `string`      | `''`          | Additional Tailwind utility classes for the outer container.                           |
| `onSequenceComplete` | `() => void`  | `-`           | Callback triggered when all claims have undergone factual verification.                |
