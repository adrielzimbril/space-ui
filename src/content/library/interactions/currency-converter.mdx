## API Reference

### CurrencyConverter Props

| Prop                  | Type                                        | Default              | Description                                                  |
| --------------------- | ------------------------------------------- | -------------------- | ------------------------------------------------------------ |
| `initialFromCurrency` | `string`                                    | `"USD"`              | Initial currency code for sending                            |
| `initialToCurrency`   | `string`                                    | `"EUR"`              | Initial currency code for receiving                          |
| `initialAmount`       | `number`                                    | `100`                | Initial numerical amount to convert                          |
| `currencies`          | `Currency[]`                                | `DEFAULT_CURRENCIES` | Custom array of available currency rates and metadata        |
| `onConvert`           | `(details: CurrencyConvertDetails) => void` | -                    | Callback triggered when the convert action button is pressed |
| `className`           | `string`                                    | -                    | Additional class name applied to outer Frame container       |
