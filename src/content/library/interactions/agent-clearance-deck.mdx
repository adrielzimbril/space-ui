## API Reference

### AgentClearanceDeck Props

| Prop                 | Type                 | Default              | Description                                                                |
| :------------------- | :------------------- | :------------------- | :------------------------------------------------------------------------- |
| `initialRequests`    | `ClearanceRequest[]` | `CLEARANCE_REQUESTS` | List of credential elevation requests with scopes, TTLs, and risk ratings. |
| `autoPlay`           | `boolean`            | `true`               | Automatically cycles and resolves clearance requests in sequence.          |
| `speed`              | `number`             | `1`                  | Speed multiplier for approval countdown timers.                            |
| `className`          | `string`             | `''`                 | Additional Tailwind utility classes for the outer card.                    |
| `onSequenceComplete` | `() => void`         | `-`                  | Callback invoked when all requests in the deck have been processed.        |
