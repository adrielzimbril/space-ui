## Overview

The **AI Chat Workspace** template is an end-to-end interface designed for conversational AI and reasoning studio workflows:

- **Sidebar Navigation**: Collapsible left sidebar containing recent threads, project folders, token counters, and account menu.
- **Model Switcher**: Dynamic selector for state-of-the-art LLMs (GPT-4o, Claude 3.5 Sonnet, Gemini 1.5 Pro) with latency, token limits, and capability tags.
- **Message Stream & Reasoning**: Markdown-rendered responses with reasoning steps, code syntax highlighting, copy action, and feedback controls.
- **Multimodal Composer**: Expandable prompt input with web search toggling, prompt attachments, token usage estimators, and keyboard shortcuts.
