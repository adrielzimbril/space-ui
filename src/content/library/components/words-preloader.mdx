## Usage

```tsx
import { WordsPreloader } from '@/components/spaceui/words-preloader'

export default function SpaceUI() {
  return (
    <WordsPreloader words={['Hello', 'bonjour', 'Ciao']} duration={2000}>
      <YourPage />
    </WordsPreloader>
  )
}
```

## Files

| File                        | Role                               |
| --------------------------- | ---------------------------------- |
| `words-preloader/index.tsx` | Overlay, word index, SVG path wipe |

## API Reference

| Prop        | Type        | Default       | Description                          |
| ----------- | ----------- | ------------- | ------------------------------------ |
| `words`     | `string[]`  | greetings     | Sequence shown before the wipe       |
| `duration`  | `number`    | `2000`        | Milliseconds before exit             |
| `className` | `string`    | —             | Root class                           |
| `children`  | `ReactNode` | fallback copy | Content revealed after the preloader |
