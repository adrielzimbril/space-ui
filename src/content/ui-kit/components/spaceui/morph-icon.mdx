## Usage

```tsx
import { MorphIcon } from '@/components/spaceui/morph-icon'
import { IconSun, IconMoon } from '@tabler/icons-react'
```

```tsx
<Button onClick={toggleTheme} size="icon" variant="ghost">
  <MorphIcon activeKey={isDark ? 'dark' : 'light'} variant="blur-scale">
    {isDark ? <IconMoon className="size-5" /> : <IconSun className="size-5" />}
  </MorphIcon>
</Button>
```

## API Reference

### MorphIcon Props

| Prop        | Type                                                   | Default        | Description                                                             |
| ----------- | ------------------------------------------------------ | -------------- | ----------------------------------------------------------------------- |
| `activeKey` | `React.Key`                                            | **Required**   | Unique key identifying current active icon/state to trigger transitions |
| `children`  | `React.ReactNode`                                      | **Required**   | The icon element to render                                              |
| `variant`   | `"blur-scale" \| "rotate-scale" \| "flip" \| "spring"` | `"blur-scale"` | Motion transition preset style                                          |
| `duration`  | `number`                                               | `0.22`         | Transition duration in seconds                                          |
| `className` | `string`                                               | `undefined`    | Additional classes applied to the motion wrapper                        |
