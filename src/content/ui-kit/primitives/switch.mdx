## Features

### Sizes

Switch toggle controls in `sm`, `default`, and `lg` sizes.

<ComponentPreview name="demo-primitives-p-switch-2" />

## Accessibility

- Follows the [WAI-ARIA Switch Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/switch/).

### Keyboard Interactions

| Key                                 | Action                                 |
| :---------------------------------- | :------------------------------------- |
| <Kbd>Space</Kbd> / <Kbd>Enter</Kbd> | Toggles the switch between on and off. |

## API Reference

### Switch

Styled wrapper for `Switch.Root` from Base UI with built-in thumb. Size is controlled via the `--thumb-size` CSS variable.
