## Usage

```tsx
import { Alert, AlertDescription, AlertTitle } from '@/components/ui/alert'
```

```tsx
<Alert>
  <AlertTitle>Your Alert Title Goes Here</AlertTitle>
  <AlertDescription>
    This is where your alert description will appear. You can customize this text with any message.
  </AlertDescription>
</Alert>
```

## API Reference

This is a custom component, not a Base UI wrapper.

### Alert

Root container for the alert.

| Prop      | Type                                                       | Default     | Description                                 |
| --------- | ---------------------------------------------------------- | ----------- | ------------------------------------------- |
| `variant` | `"default" \| "error" \| "info" \| "success" \| "warning"` | `"default"` | Controls the alert styling and color scheme |

### AlertIcon

Container for the alert icon. Supports standalone icon rendering or badge container styling.

| Prop    | Type      | Default | Description                                                                  |
| ------- | --------- | ------- | ---------------------------------------------------------------------------- |
| `badge` | `boolean` | `false` | Renders the icon inside a badge container styled according to parent variant |

### AlertTitle

Title text for the alert. Renders as a styled `div`.

### AlertDescription

Description text for the alert. Renders as a styled `div` with muted foreground color.

### AlertAction

Container for action buttons. Automatically positions to the right on larger screens.
