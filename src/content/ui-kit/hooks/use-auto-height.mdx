## Usage

```tsx
import { useAutoHeight } from '@/hooks/use-auto-height'

const { ref, height } = useAutoHeight([items])
<div style={{ height }}>
  <div ref={ref}>{items}</div>
</div>
```

## API Reference

### Parameters / Props

| Parameter | Type             | Default | Description      |
| :-------- | :--------------- | :------ | :--------------- |
| `deps`    | `DependencyList` | `[]`    | Dependency list. |

### Return Value

| Property | Type                     | Description              |
| :------- | :----------------------- | :----------------------- |
| `ref`    | `RefObject<HTMLElement>` | Inner measurable ref.    |
| `height` | `number`                 | Calculated height in px. |
