## Usage

```tsx
import { useLocalStorage } from '@/hooks/use-local-storage'

const [count, setCount, remove] = useLocalStorage('key', 0)
```

## API Reference

### Parameters / Props

| Parameter      | Type     | Default    | Description     |
| :------------- | :------- | :--------- | :-------------- |
| `key`          | `string` | _required_ | Storage key.    |
| `initialValue` | `T`      | _required_ | Fallback value. |

### Return Value

| Return Type                         | Description                 |
| :---------------------------------- | :-------------------------- |
| `[T, (val: T) => void, () => void]` | Value, setter, and remover. |
