## Usage

```tsx
import { isNegative } from '@/utils/is-negative'

isNegative(-5) // true
isNegative(0) // false
```

## API Reference

### Parameters / Props

| Parameter | Type     | Default    | Description      |
| :-------- | :------- | :--------- | :--------------- |
| `num`     | `number` | _required_ | Number to check. |

### Return Value

| Return Type | Description                |
| :---------- | :------------------------- |
| `boolean`   | True if strictly negative. |
