## Usage

```tsx
import { useClipboard } from '@/hooks/use-clipboard'

const { copy, copied } = useClipboard({ timeout: 2000 })
copy('Text to copy')
```

## API Reference

### Parameters / Props

| Parameter         | Type     | Default | Description                           |
| :---------------- | :------- | :------ | :------------------------------------ |
| `options.timeout` | `number` | `2000`  | Timeout in ms before `copied` resets. |

### Return Value

| Property | Type                                 | Description                       |
| :------- | :----------------------------------- | :-------------------------------- |
| `copy`   | `(text: string) => Promise<boolean>` | Triggers clipboard copy.          |
| `copied` | `boolean`                            | Whether text was recently copied. |
| `reset`  | `() => void`                         | Resets copied state immediately.  |
