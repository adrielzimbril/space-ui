## Overview

Space UI relies on high-contrast semantic color tokens paired with subtle alpha-translucent borders (`--alpha(...)`) and layered drop shadows to produce visual hierarchy and depth.

## Palette & Semantic Tokens

| Token         | Light Mode                                               | Dark Mode                                                | Usage                         |
| :------------ | :------------------------------------------------------- | :------------------------------------------------------- | :---------------------------- |
| `background`  | <ColorSwatch value="hsl(0 0% 100%)" />                   | <ColorSwatch value="hsl(0 0% 9%)" />                     | Application canvas background |
| `foreground`  | <ColorSwatch value="hsl(222 46% 11%)" />                 | <ColorSwatch value="hsl(0 0% 100%)" />                   | Default body text             |
| `card`        | <ColorSwatch value="hsl(0 0% 100%)" />                   | <ColorSwatch value="hsl(0 0% 4%)" />                     | Cards, panels, surfaces       |
| `primary`     | <ColorSwatch value="hsl(0 0% 4%)" />                     | <ColorSwatch value="hsl(0 0% 98%)" />                    | Primary buttons & highlights  |
| `secondary`   | <ColorSwatch value="hsl(240 5% 96%)" />                  | <ColorSwatch value="hsl(240 4% 16%)" />                  | Secondary actions & badges    |
| `muted`       | <ColorSwatch value="hsl(240 5% 96%)" />                  | <ColorSwatch value="hsl(240 4% 16%)" />                  | Subtle container backgrounds  |
| `destructive` | <ColorSwatch value="hsl(0 84% 60%)" />                   | <ColorSwatch value="hsl(0 84% 60%)" />                   | Errors, delete actions        |
| `info`        | <ColorSwatch value="hsl(220 96% 57%)" />                 | <ColorSwatch value="hsl(220 96% 57%)" />                 | Informational callouts        |
| `success`     | <ColorSwatch value="hsl(122 61% 42%)" />                 | <ColorSwatch value="hsl(122 61% 42%)" />                 | Completed/success states      |
| `warning`     | <ColorSwatch value="hsl(38 95% 50%)" />                  | <ColorSwatch value="hsl(38 95% 50%)" />                  | Cautionary warnings           |
| `border`      | <ColorSwatch value="--alpha(var(--color-black) / 8%)" /> | <ColorSwatch value="--alpha(var(--color-white) / 8%)" /> | Translucent borders           |
